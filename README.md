# Greed Island Online

A private, multiplayer 3D adventure game inspired by the broad game systems of collectible-card RPGs and open-world exploration. This project uses original characters, world design, card names, artwork, and audio.

## Development status

The repository scaffold is being established. The first milestone is a playable browser-based island prototype; multiplayer persistence, quests, battles, trading, and the full card progression system will follow in staged milestones.

## Planned stack

- Next.js + TypeScript for the web application
- React Three Fiber / Three.js for the 3D world
- Colyseus for authoritative real-time multiplayer rooms
- PostgreSQL + Prisma for accounts and persistent progression
- A separately hosted game server for multiplayer sessions

## Local development

```bash
npm install
npm run dev
```

Then open http://localhost:3000.
